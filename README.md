## فارسی

چای سرد است، سامانه قطع است و مشتری می‌گوید «فقط یک دقیقه کار دارم!» در نقش امیرعلی، صاحب کافی‌نت زئوس در تهران بارانی، سفارش‌ها و استرس را مدیریت کن و با راز هارد ده‌گیگی روبه‌رو شو.

### امکانات نسخهٔ فعلی

- «آموزش و تمرین» در منوی اصلی: ۱۲ مرحلهٔ تعاملی، جدا از ذخیره و پول داستان.
- سه مشتری تازه: صاحب‌ملک، دانشجوی دکتری و دلال رمزارز؛ هر نفر سه مأموریت متفاوت در سه روز.
- N یا د برای حالت دولوپر؛ اسکیپ هر مشتری با انتخاب راضی (دستمزد پایه) یا ناراضی (بدون دستمزد)، همراه لغو و مکث زمان هنگام سؤال.

- صفحهٔ داستان تمام‌صفحه با تصویر شخصیت اصلی در راست و طرف گفت‌وگو در چپ؛ دو حباب، ادامه و بازخوانی گفت‌وگو، تغییر زبان داخل صحنه و حفظ محل خواندن. شروع کار و تصمیم‌های داستانی دکمه‌های جدا دارند.
- سه روز کاری؛ هر بازی پنج مشتری از پنج گروه انتخاب می‌شوند و هر روز با مأموریت همان روز برمی‌گردند: پنج مراجعه در روز و مجموعاً ۱۵ سفارش. مجموعهٔ بازی همچنان ۱۴ مشتری و ۴۲ مأموریت دارد.
- دفتر مشتری‌ها با پنج گروه و نمایش سه مأموریت هر نفر؛ داستان امیرعلی، شاهین، مریم و عمو رحیم؛ هفت فصل انتخابی شبانه در روزهای ۴ تا ۱۰ و دو پایان.
- تایمر گرافیکی ۶۰ ثانیه‌ای؛ در ثانیهٔ ۳۰ عصبانیت و ۱۵ واحد درصد استرس؛ در ثانیهٔ ۶۰ رفتن بدون پرداخت.
- در متوسط و سخت، اشتباه تا تحویل پنهان است؛ مشتری توضیح می‌دهد و مسخره می‌کند، ۲۵ واحد درصد استرس اضافه و کار از اول انجام می‌شود.
- خرید سه سطح ارتقای سیستم و پرینتر با درآمد شیفت؛ دو پایان خوب و بد.
- در هر روز، همهٔ مشتری‌ها دقیقاً یک بار با ترتیب تصادفی می‌آیند؛ مأموریت دوم و سوم فقط در روزهای دوم و سوم باز می‌شوند.
- سه درجهٔ سختی: آسان، معمولی و سخت. گزارش و داستان ابتدای هر روز تا شروع کار، زمان را نگه می‌دارد.
- کامپیوتر با شش برنامه: مرورگر، مدیریت فایل، ویرایش عکس، اسکنر، حسابداری و دفتر مشتری‌ها؛ فرم چندفیلدی، انتخاب فایل و ورود مبلغ با ارقام فارسی.
- استرس پویا، احتمال سوتی بالای ۵۰٪ و پایان بازی در ۱۰۰٪.
- چهار نقطهٔ کاری: کامپیوتر، پرینتر، قفسهٔ کنسول و برگه‌های روی میز. با کلیک روی استکان چای استرس کم می‌شود؛ چای، رادیو، سرویس پرینتر و نفس عمیق از منوی استراحت هم در دسترس‌اند.
- رابط فارسی راست‌به‌چپ و انگلیسی چپ‌به‌راست، صدای اختیاری و تنظیم افکت‌ها.
- ذخیرهٔ خودکار پیشرفت، درآمد، ترتیب مراجعه‌ها و عملیات در حال انجام در مرورگر.

عکس میز کنسول با انتخاب مستقیم PS3 و PS4، تصویر خیابان و پاساژ و چهار شخصیت اصلی در داستان استفاده می‌شوند. بستن دفتر به صفحهٔ قبلی برمی‌گردد و بازی درست ادامه پیدا می‌کند. بخش شهر و تعقیب در این نسخه با روایت و انتخاب اجرا می‌شود. در مدیریت فایل، کپی آزمایشی هارد را با C یا دکمه پشت فرم خودرو بپوشان؛ Alt+Tab معمولاً متعلق به ویندوز است.

### اجرا

نسخهٔ سایت: `index.html` را باز کن؛ پوشهٔ `assets/` باید کنارش باشد.

نسخهٔ مستقل: `offline.html` را باز کن؛ تصاویر و فونت داخل آن جاسازی شده‌اند. بازی به نصب پکیج یا اتصال به اینترنت نیاز ندارد.

### ساخت و آزمون

ساخت به Python 3 و آزمون‌ها به Node.js 20 یا جدیدتر نیاز دارند. این ابزارها برای بازی کردن لازم نیستند.

```sh
python build.py
node --test tests/engine.test.cjs tests/app.test.cjs
```

در ویندوز، `py -3 build.py` جایگزین دستور ساخت است. بعد از تغییر سورس، خروجی‌های `index.html` و `offline.html` را دوباره بساز و همراه تغییرات در مخزن قرار بده. آزمون‌های رابط از DOM آزمایشی استفاده می‌کنند و جای بررسی بصری مرورگر را نمی‌گیرند.

### انتشار در GitHub Pages

1. فایل‌ها را در مخزن قرار بده؛ `index.html` و پوشهٔ کامل `assets/` باید در ریشه باشند.
2. در تنظیمات مخزن، **Settings → Pages → Build and deployment** را باز کن.
3. برای **Source** گزینهٔ **Deploy from a branch** را انتخاب کن؛ شاخهٔ حاوی فایل‌ها، مثلاً `main`، و پوشهٔ **/(root)** را تعیین کن.
4. پس از استقرار، نشانی سایت در همان صفحه نمایش داده می‌شود.

فایل `.nojekyll` برای انتشار مستقیم فایل‌های ثابت در پروژه قرار دارد. ساخت Python را محلی انجام بده؛ گردش‌کار خودکار برای ساخت پروژه در GitHub Actions تنظیم نشده است.

[مستند رسمی تنظیم انتشار GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

### ذخیره و منابع

ذخیره‌ها به مرورگر و نشانی اجرای بازی وابسته‌اند؛ تغییر مرورگر یا انتقال از فایل محلی به سایت لزوماً ذخیره را منتقل نمی‌کند. پاک‌کردن داده‌های سایت ذخیره را حذف می‌کند. تمام حساب‌ها و عملیات داخل بازی ساختگی‌اند. صندوق، درآمد سفارش‌ها و معامله‌های انتخاب‌شده را نشان می‌دهد. پایان خوب از قطع معاملهٔ شاهین، تحویل‌ندادن داده و پاک‌سازی با عمو رحیم به دست می‌آید.

فونت Vazirmatn تحت مجوز SIL Open Font License 1.1 است؛ متن مجوز در `src/strings.json` و خروجی‌ها حفظ شده است. مخزن فعلاً فایل `LICENSE` برای مجوز عمومی کد و تصاویر ندارد.

## English

The tea is cold, the portal is down, and the customer says, “It will only take a minute!” Play as Amirali, run Zeus in rainy Tehran, and uncover the secret of a hidden ten-gigabyte sector.

### Current features

- Main-menu Learn and practise: 12 interactive lessons using a separate practice room. Campaign progress and money remain intact.
- Three new customers: landlord, PhD student and crypto broker, each with three distinct daily missions.
- N or د toggles developer mode. Each skip asks for Satisfied (base pay) or Unhappy (no pay), with cancel and a frozen clock while deciding.

- A dedicated full-screen story scene: the supplied Nima protagonist portrait stays right and the chapter partner stays left in both languages. Paired speech bubbles advance or replay dialogue; reading progress survives the daybook, menu and reload. Work and story choices use separate buttons.
- Three workdays with five selected customers, one per category: five visits daily and 15 per run. The same five return with a different mission each day. The full catalog keeps all 14 customers and 42 missions.
- A customer daybook with five categories and all three missions per person; Amirali, Shahin, Maryam and Uncle Rahim’s story; seven night choice chapters on days 4–10 and two endings.
- Graphical 60-second patience: mockery and +15 stress points at 30s, unpaid departure at 60s.
- Normal/Hard errors stay hidden until delivery, then trigger specific customer mockery, +25 stress points and rework.
- Buy three levels of computer and printer upgrades with shift earnings; reach a good or bad ending.
- Each customer appears once per day, shuffled without consecutive repeats. Missions two and three belong to days two and three.
- Three difficulties: Easy, Normal and Hard. Opening reports and chapters pause time until the player opens for the day.
- Six computer apps: browser, file manager, photo editor, scanner, accounts and daybook. Fill multiple fields, select file bundles and enter invoice totals with Persian or Latin digits.
- Dynamic stress, possible mistakes above 50%, and game over at 100%.
- Four scene stations: computer, printer, console shelf and desk documents. Click the tea glass to reduce stress; tea, radio, printer maintenance and breathing are also available in the break menu.
- Persian RTL and English LTR interfaces, optional synthesized audio and an effects toggle.
- Browser autosave for progress, earnings, visit order and active operations.

The console shelf opens the supplied bench image with PS3/PS4 hotspots. Night chapters use the supplied street, market and four story portraits. Closing the daybook restores its parent screen and resumes the visit correctly. City travel and pursuit use narrated choices. In File Manager, press C or Cover to hide the simulated copy behind a vehicle form; Alt+Tab is usually reserved by the OS.

### Play

Hosted version: open `index.html` with the `assets/` folder beside it.

Standalone version: open `offline.html`; images and the font are embedded. Playing requires no package installation or internet connection.

### Build and test

Building requires Python 3. Tests require Node.js 20 or later. Neither tool is needed to play.

```sh
python build.py
node --test tests/engine.test.cjs tests/app.test.cjs
```

On Windows, `py -3 build.py` is an alternative build command. Rebuild `index.html` and `offline.html` after source changes and include the generated outputs in your repository update. UI tests use a DOM stub and do not replace visual browser testing.

### Publish with GitHub Pages

1. Add the files to your repository, keeping `index.html` and the complete `assets/` folder at its root.
2. Open **Settings → Pages → Build and deployment**.
3. Set **Source** to **Deploy from a branch**, choose the branch containing the files, such as `main`, and select **/(root)**.
4. Once deployment finishes, use the site address shown on that page.

The included `.nojekyll` file supports direct static-file publishing. Run the Python build locally; an automated GitHub Actions build workflow is not configured.

[Official GitHub Pages publishing documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

### Saves and assets

Saves belong to the browser and the location used to open the game. Switching browsers or moving from a local file to the hosted site does not necessarily transfer a save. Clearing site data removes its save. All accounts and service operations in the game are fictional. The till includes orders and chosen fictional deals. The good ending requires ending Shahin’s arrangement, never handing data over, and erasing it with Uncle Rahim.
